# OpenTelemetry Java Agent

- Version: `2.31.1`
- Source: https://github.com/open-telemetry/opentelemetry-java-instrumentation/releases/tag/v2.31.1
- File: `opentelemetry-javaagent.jar`
- SHA-256: `bbf83c151b6400709e2f225bdd07a04f839d9d13b8b93464241333fd25d3e3ba`

The JAR is mounted read-only by both application containers and attached through
`JAVA_TOOL_OPTIONS`. It provides Spring Web and Spring Kafka instrumentation
without application-level span code.
